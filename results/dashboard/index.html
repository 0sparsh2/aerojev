Every system

Accuracy is the mean over the nine trained questions. Gold and gold2 are hand-written records (gold2 written blind); test uses wording held out from training. Quantized rows without their own evaluation repeat the fp32 accuracy.

Task. Each record (supplier email, ERP exception, chat message, quality notification, risk alert, portal notice or call notes) gets nine decisions: event type, commodity, impact severity, line-stop risk, recommended action, export control, counterfeit suspicion, sole source and delay bucket. Labels follow a written playbook applied to each record's facts.

Model. Qwen base models with LoRA trained on the label-token logits only (RFDT-style). The answer is the softmax over each question's allowed label tokens at a single readout position, so nothing is generated. Training data is synthetic and template-split; the gold sets are written by hand in formats the generator never produces.

Hosts. An Apple M4 laptop (four threads used) and a four-vCPU x86 cloud VM with an Intel Xeon. llama.cpp ran CPU-only. The hosted Jev API latency is the client-side median round trip.
